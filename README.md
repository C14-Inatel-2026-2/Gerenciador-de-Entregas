Motoristas e Veículos

A classe Motorista guarda informações como nome, CNH e status. O status pode ser disponível, em viagem ou indisponível. Também criamos um método para atualizar o status e verificar se o valor informado é válido.

A classe Veiculo guarda informações como placa, modelo, capacidade de carga, consumo médio e custo por quilômetro. Esses dados ajudam a organizar os veículos utilizados nas entregas.

A listagem de motoristas vai permitir visualizar os motoristas cadastrados e seus status, para saber quais estão disponíveis para realizar entregas.
